# Online Resource 1 (supplementary material)

`TRUST-BC_Online_Resource_1.docx` is the supplementary file submitted with the manuscript. It contains
Tables S1 (TRIPOD+AI), S1b (TRIPOD+AI for Abstracts), S2a/S2b (PROBAST+AI author self-assessment),
Figure S1 (participant flow), Tables S3-S9, Section S10 (extended methods, results and limitations),
Section S11 (model card, Table S10) and Section S12 (dataset datasheets, Table S11).

## `tables/`: every table as CSV/JSON

| File | Online Resource item |
|---|---|
| `S1_tripod_ai_checklist.csv` | Table S1 |
| `S1b_tripod_ai_abstracts_checklist.csv` | Table S1b |
| `S2a_probast_ai_development.csv`, `S2b_probast_ai_evaluation.csv` | Table S2a, S2b |
