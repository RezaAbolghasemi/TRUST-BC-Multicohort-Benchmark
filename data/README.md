# Data Sources

This repository does **not** redistribute raw patient-level data. All three cohorts
used by TRUST-BC are publicly available from their original sources. The pipeline
(`src/trust_bc_multicohort_benchmark.py`) downloads or loads each cohort automatically, as described below.

| Cohort | Access method in pipeline | Original source | License / terms |
|---|---|---|---|
| **WBCD** (Wisconsin Diagnostic Breast Cancer, *n* = 569) | Loaded automatically via `sklearn.datasets.load_breast_cancer()` — no download needed. | [UCI Machine Learning Repository](https://archive.ics.uci.edu/ml/datasets/breast+cancer+wisconsin+(diagnostic)) | Public domain / UCI terms of use |
| **Coimbra** (serum biomarkers, *n* = 116) | Downloaded automatically from the UCI repository at runtime (SHA-256 checksum is printed and logged for provenance). | [UCI Machine Learning Repository](https://archive.ics.uci.edu/ml/datasets/Breast+Cancer+Coimbra) | Public domain / UCI terms of use |
| **SEER** (5-year mortality + survival, *N* = 4,024) | **Manual step required.** Download the curated extraction and place the CSV in the working directory (or pass its path) before running the script — see below. | [Kaggle: Breast Cancer (SEER) Dataset](https://www.kaggle.com/datasets/reihanenamdari/breast-cancer) | Subject to Kaggle dataset terms; underlying data governed by the NCI SEER Program |

## Obtaining the SEER extraction

The SEER cohort cannot be bundled in this repository or auto-downloaded because it
requires a free Kaggle account and acceptance of the dataset's terms of use.

1. Create a free account at [kaggle.com](https://www.kaggle.com) if you do not have one.
2. Download the dataset from
   [kaggle.com/datasets/reihanenamdari/breast-cancer](https://www.kaggle.com/datasets/reihanenamdari/breast-cancer).
3. Place the resulting CSV file in the directory from which you run `src/trust_bc_multicohort_benchmark.py`
   (the script auto-detects any file matching `*SEER*.csv` / `*seer*.csv` in the
   current working directory), **or** rename it to `SEER.csv`.
4. Run the pipeline as described in the top-level `README.md`. If no matching file is
   found and the script is running inside Google Colab, it will instead prompt for an
   interactive upload.

For researchers seeking the authoritative, fully governed version of this extraction,
the equivalent cohort definition (female patients with infiltrating ductal or lobular
carcinoma, SEER histology code 8522/3, diagnosed 2006–2010, November 2017 submission)
can be reproduced directly from **SEER\*Stat** under the appropriate institutional Data
Use Agreement with the National Cancer Institute. See Section 2.1 of the manuscript
(`paper/TRUST-BC_manuscript_v1.1.pdf`) for full cohort inclusion/exclusion criteria.

If you only want to inspect or reproduce the figures/tables reported in the paper

[`results/`](../results/).

## SEER file version and label definition (v1.1)

The analysed file has 4,024 rows and 16 columns (including an empty `Unnamed: 3` column),
with `Grade` coded as text (e.g. `Moderately differentiated; Grade II`), `Survival Months`
up to 107 and `Status` in {Alive, Dead}. `Status` is all-cause vital status.

The 5-year classification label in v1.1 is:
- event: `Status == Dead` and `Survival Months <= 60` (458 patients);
- non-event: alive with `Survival Months >= 60`, or death after month 60 (2,812 patients);
- excluded: alive with `Survival Months < 60` (754 patients).

`python scripts/seer_revision_core.py` functions (`load_seer`) implement this definition.
